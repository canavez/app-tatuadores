# App para Tatuadores

Sistema para tatuadores gerenciarem agenda, clientes, finanças e materiais. Projeto de portfólio de um desenvolvedor aprendendo Java para conseguir a primeira vaga.

## Stack
- Backend: Java 25 (Temurin) + Spring Boot + PostgreSQL + Flyway + JUnit/Mockito
- Frontend: React + TypeScript + Vite (web responsivo, não app nativo)
- IDE: VS Code com Extension Pack for Java e Spring Boot Extension Pack
- Ambiente: Windows 11, PowerShell

## Progresso
O plano e o status estão em [ROADMAP.md](ROADMAP.md). Consulte-o no início de cada sessão e marque os checkboxes conforme as tarefas forem concluídas.

## Como trabalhar neste projeto
- Responda sempre em português (BR).
- O objetivo é **aprender**, não só entregar: explique cada conceito no momento em que ele aparece, com o "porquê", e aponte o que costuma cair em entrevistas.
- Nas etapas iniciais, o Tadeu digita o código e o Claude explica e revisa. Documentação (README, ROADMAP) o Claude pode escrever. Conforme ele ganhar base, o Claude pode gerar mais código para ele revisar.
- Comandos de terminal (git, build) devem ser passados para ele rodar, explicando o que cada um faz.
- Ao fim de cada etapa, faça perguntas no estilo de entrevista sobre o que foi construído.
- Commits: mensagens em português, no imperativo ("Adiciona…", "Corrige…").
